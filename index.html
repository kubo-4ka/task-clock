勤務と時間

        

          
          
          
          
          
          
          
          
          
        

        
夜勤や休日夜間の障害対応がある場合は「その日の最初の記録から」がおすすめです。最初に計測した時刻が始業になり、最後の記録から一定時間（既定3時間）空くとその日の勤務は終了とみなします。日付をまたぐ勤務は「日付の区切り時刻」（例 05:00）で前日扱いにできます。

      


      

        
休日・祝日

        

        
祝日・会社の休日・出勤日はカレンダーの日付をクリックして登録します。登録した日はクリックで名前の変更や削除ができます。

        

          

            
            
            
            
          

          

          
登録した休日 休みの曜日 出勤日

        

        

          
          
        

        

        

          登録一覧
          

          

        

        
休日は基準時間0として扱い、作業した時間はすべて「基準超過（休日作業）」に入ります。休日一覧はエクスポートにも含まれ、別のPCでマージすると新しく編集された方の一覧が使われます。

      


      

        
通知

        
        
        

          
          
          
        

        
詰まりアラーム

        
        

          
          
          
        

        
        
通知はアプリ（またはタブ）を開いている間だけ動きます。最小化していても通知されます。

      


      

        
バックアップ・端末間の引き継ぎ

        
データはこのブラウザ内に保存されます。別のPCとは日時付きJSONファイル（NAS等の共有フォルダ推奨）でマージします。同じ項目は更新日時が新しい方を採用し、削除も引き継ぎます。

        

        
        
ブラウザの仕様上、選んだフォルダの名前しか取得できないため、フルパスはここにメモしておけます。

        

          
          
          
          
          
        

        
        
        
取り込める形式: Task Clock の JSON / Task Flow の JSON（タスク・Project）/ Task Time Log の CSV（時間記録）

        

      


      

        
入力のコツ

        
    
          
  • 入力欄は @Project #タグ ~30m（見積）^10/9（期限）!today !next !wait !cal !later *毎週（繰り返し）を解釈します。
    • 
          
  • タスクの ▶ で計測すると「Project › 分類 › タスク名」とタグが自動で記録に入ります。別タスクの ▶ で切り替わります。
    • 
          
  • 迷ったら「▶ すぐ開始」。後で記録画面やホームから割り当てられます。
    • 
          
  • ホームのタイムラインで空いている時間（未記録）をクリックすると、その時間をタスクに割り当てられます。
    • 
          
  • ショートカット: N 入力欄へ / Space 停止・直前の作業を再開 / 1～6 画面切替
    • 
        

      


      

        
危険な操作

        
タスク・Project・記録をすべて消去します。設定は残ります。実行前にエクスポートしてください。
