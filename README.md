# Task Clock

タスク管理と作業時間の記録・集計をひとつにした、個人向けのインストール可能なWebアプリ（PWA）です。HTML / CSS / JavaScript のみで動作し、外部ライブラリやサーバー側への保存はありません。

**タスクが Project・分類・タグを持っている**ので、タスクの ▶ を押すだけで「Project › 分類 › タスク名」とタグが記録に入ります。時間記録のために分類を入力し直す必要はありません。

# DEMO

https://kubo-4ka.github.io/task-clock/

## 起動・インストール

### ローカルで起動してアプリとしてインストール（おすすめ）
1. Node.js が入ったPCで `tools/start_app.bat` を実行
   （`node tools/serve.js` で http://localhost:8790/ を起動し、Edgeの小型アプリウインドウで開きます）
2. ヘッダーの「インストール」（またはブラウザのメニュー「アプリをインストール」）
3. 以後はスタートメニュー/タスクバーから独立ウインドウで起動できます

### Webサーバーに置く場合
フォルダ一式を GitHub Pages などに置けば動きます（https ならインストール・OS通知・共有フォルダ連携とも利用可）。登録データは各ブラウザ内に保存され、公開先へは送られません。

### index.html を直接開く場合
`file://` でも基本機能は動きますが、インストール・OS通知・共有フォルダ連携は使えません。

> データは「開いたURL（オリジン）」ごとに別保存です。開くURLを変えるときは、エクスポート→マージで移してください。

## 1日の流れ

1. **朝**：ホームで「要対応」を確認し、今日やるものに ☆。共有フォルダを設定していれば、起動時に最新データのマージを提案します
2. **思いついたら**：上の入力欄に打って Enter（Inbox に入ります）
3. **作業する**：タスクの ▶。別タスクの ▶ を押すと自動で切り替わります。迷ったら「▶ すぐ開始」（後で割当）
4. **割り込み**：⚡ → 終わったら「■ 終了して戻る」で元の作業を再開
5. **終わったら**：✓（計測中なら停止＋完了）
6. **一日の終わり**：「終業」→ 未記録のすき間・未割当を確認してエクスポート

### 入力欄の記法

```
見積書作成 @A案件 #資料 ~1h30m !today ^10/9
定例会議 @社内 !cal ^10/6 *毎週
```

| 記法 | 意味 |
|---|---|
| `@名前` | Project（なければ自動作成） |
| `#タグ` | タグ（複数可） |
| `~30m` `~1.5h` `~1h30m` | 見積 |
| `^10/9` `^2026-10-09` `^明日` | 期限・予定日 |
| `!today` | 今日やる |
| `!next` `!wait` `!cal` `!later` | 状態（省略時は Inbox） |
| `*毎日` `*平日` `*毎週` `*毎月` | 繰り返し |

### キーボード
`N` 入力欄へ / `Space` 停止・直前の作業を再開 / `1`～`6` 画面切替

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | 今日の実績と基準時間、未記録のすき間、Today、要対応、今日のタイムライン、Next |
| タスク | Today / Inbox / Next / Waiting / Calendar / Later / 完了（切替は画面上部に固定）。☆・▶・状態移動 |
| Project | 未完了数、今月・累計の実績、残り見積、Nextなし警告 |
| 記録 | 年→月→日の折り畳み（最新の年と月だけ開いた状態で表示）。編集・複製・削除、▶で同じ内容を再計測、未割当の割当、分類・タグの一括置換 |
| 集計 | 期間 × 実績/予定 × 軸（Project／Project›分類／タスク／タグ／分類1～3）。内訳、日別、見積と実績、時間配分の気づき、報告用テキスト、CSV |
| 設定 | 表示、勤務と時間、休日・祝日、通知、バックアップ・引き継ぎ（項目ごとに折り畳み。開いた項目は次回も開いたまま） |

### 完了と Today
完了にすると Today の一覧から消え、「元に戻す」で Today に戻ります。

### 繰り返し
タスクに期限と繰り返し（毎日／勤務日ごと／毎週／毎月）を設定すると、完了時に次回分が自動で作られます。状態が Calendar の繰り返し（定例会議など）は、完了しなくても日付が過ぎると次回へ送られます。「勤務日ごと」は休日を飛ばします。

### 見積と予定
未完了で期限と見積があるタスクは、見積の残り時間が期限日の「予定」として集計に入ります。集計の「見積と実績」では、完了タスクの実績÷見積の倍率も表示します。

## 勤務時間の考え方

| 設定 | 既定 | 説明 |
|---|---|---|
| 勤務日の基準時間 | 8:00 | これを超えた分を基準超過として集計。休日は0（作業はすべて休日作業） |
| 始業の判定 | その日の最初の記録から | 夜勤・休日夜間の障害対応など、始業が日によって変わる場合に向く。「勤務日は始業時刻から」にすると、勤務日は固定の始業時刻から未記録を検出 |
| 勤務日の始業時刻 | 09:00 | まだ記録のない勤務日に「計測なし」を知らせる起点。「勤務日は始業時刻から」の場合は未記録の検出にも使う |
| 日付の区切り時刻 | 00:00 | 例 05:00 にすると 0:00～4:59 の作業を前日として扱う（夜勤の日またぎ） |
| 未記録とみなす空き | 10分 | タイムラインに「未記録」として表示し、クリックでタスクを割当 |
| 記録しない短い計測 | 30秒 | 押し間違いを記録に残さない |
| 停止時に終了時刻を確認 | 4時間超 | 止め忘れの補正 |
| 勤務終了とみなす無記録の時間 | 3時間 | 最後の記録からこの時間空くと、その日の勤務は終わったものとみなす |
| 月の基準超過の上限目安 | 45時間 | ホームに今月の基準超過と月末見込みを表示し、集計の「気づき」で超過・接近を知らせる |

最後の記録から「勤務終了とみなす無記録の時間」が過ぎるか「終業」を押すと、その日の勤務は終わったものとみなし、未記録の検出や「計測なし」の通知を止めます。終業後に再び計測を始めると再開します。

### 休日・祝日
設定 →「休日・祝日」で管理します。

- **休みの曜日**（既定：土日）
- **カレンダー**：日付をクリックすると登録画面が開き、名前と種類（休日／出勤日）を入れて保存します。登録済みの日をクリックすると名前の変更や削除ができます。出勤日は、休みの曜日に出勤する日（土曜出勤など）に使います
- **日付を入力して登録**：カレンダーを移動せずに日付を直接指定して登録できます
- **祝日をまとめて追加**：表示中の年の祝日を暦どおりに追加します（登録済みの日はそのまま）
- **登録一覧**：年ごとに一覧でき、個別の編集・削除、その年の登録の一括削除ができます

初回起動時には今年の祝日が登録されています。祝日の改正や臨時の祝日、会社の休日は、カレンダーや一覧から追加・変更・削除してください。10月以降に翌年の祝日が未登録の場合は、設定画面でお知らせします。

休日一覧と休みの曜日はエクスポートに含まれ、別のPCでマージすると、より新しく編集された方の一覧が使われます。

休日は日別グラフで赤く表示し、「時間配分の気づき」で休日作業の日数と時間を示します。

### 基準超過（時間外）の見方
基準超過＝勤務日に基準時間を超えた分＋休日に作業した時間です。ホームの「今月の基準超過」には、経過した勤務日のペースが続いた場合の月末見込みも表示します。上限目安（既定45時間）を超えた月・超えそうな月・80%に達した月は、集計の「時間配分の気づき」に表示します。

## 通知

アプリ（またはブラウザのタブ）を開いている間、最小化していても通知します。画面を見ているときは画面内メッセージ、別の作業中は OS の通知（設定で許可した場合）を使います。

| 通知 | 既定 | 繰り返し |
|---|---|---|
| 勤務中に計測していない | 30分 | 計測を始めるまで30分ごと（30分・1時間・1時間30分…） |
| 計測中の経過（「〇〇が30分経過」） | 30分 | 停止するまで30分ごと |
| 日時つきの予定・タスク | 15分前 | 15分前と開始時刻の2回 |
| 詰まり（期限超過・Inbox放置・Waiting確認日・Nextなし・見積超過・計測しっぱなし） | 2時間 | 該当がある間は2時間ごと |

「勤務中」は、その日の最初の記録から、最後の記録後「勤務終了とみなす無記録の時間」が過ぎるか「終業」を押すまでです。まだ記録のない勤務日は、始業時刻（設定）から数えて知らせます。休日は、記録を始めるまで知らせません。

OS の通知を使うには、設定 →「OSの通知を使う」をオンにして、ブラウザの確認で許可してください。アプリを閉じている間は通知されません。

画面内のメッセージ（「元に戻す」など）は画面下に表示され、×で閉じられます。

## 時間配分の気づき（集計）
10時間以上の日、勤務日の基準超過日、休日作業、1日平均Project数4以上、30分未満の記録30%以上、タグ「割り込み」20%・「会議」10%・「資料探索」10%・「障害対応」8%以上、予定だけで基準を超える日、タスク未割当の実績15%以上を検出します。いずれも診断ではなく、掘り下げる場所を見つけるための目安です。

## データと端末間の引き継ぎ

- 保存先はブラウザの localStorage（タスク・Project・記録）。計測中のタイマーと設定は端末ごと
- **共有フォルダ連携**（Edge / Chrome）：NAS等のフォルダを選ぶと `task_clock_YYYYMMDD_HHMMSS.json` を書き出し、「フォルダの最新をマージ」で取り込み。ブラウザはフォルダ名しか取得できないため、フルパスは設定欄にメモできます
- マージ規則：同じIDは更新日時が新しい方を採用。削除は削除履歴で引き継ぐため、古いファイルを後から取り込んでも削除済みは復活しません。何度取り込んでも重複しません
- 任意で「変更があれば1時間ごとに自動エクスポート」「未エクスポートで閉じるとき警告」
- 目安容量：記録 約2,400件で約0.8MB。1万件以上を保持できます

### 取り込み方
- 設定 →「ファイルを指定してマージ」
- 設定 →「テキストを貼り付けてマージ」：エクスポートしたJSONやCSVの中身をそのまま貼り付けます。ファイルを選びにくいスマートフォン向けで、「クリップボードから読み込む」も使えます

### 取り込める形式

- Task Clock の JSON
- Task Flow の JSON（タスク・Project・状態・期限・確認日・メモ）
- Task Time Log の CSV（時間記録。タスク未割当の記録として入り、集計の「分類1～3」軸で見られます）

## 試用データ

いずれも架空のデータです。設定 →「ファイルを指定してマージ」（または貼り付け）で読み込めます。試す前に、別のブラウザプロファイルを使うか、エクスポートしておくことをおすすめします。

| ファイル | 内容 |
|---|---|
| `test-data/sample_task_clock_20261002.json` | 標準的な6週間分（Project 4・タスク 19・記録 300件、繰り返しの予定を含む） |
| `test-data/sample_overtime_202607-202610.json` | 時間外の確認用。2026年7月～10月2日（Project 3・タスク 9・記録 574件）。平日夜勤（翌4:50まで）、夜勤明けの休み、日曜未明・土曜夜の障害対応やリリース、祝日出勤（海の日・山の日・敬老の日）を含む |

時間外確認用データの月ごとの基準超過（基準 8:00、休日は土日＋2026年の祝日、日付の区切り時刻 05:00 で集計した場合）：

| 月 | 基準超過 | うち休日作業 | 上限目安45時間 |
|---|---|---|---|
| 2026年7月 | 36:00 | 7:00 | 下回る（80%） |
| 2026年8月 | 52:20 | 12:10 | 超過 |
| 2026年9月 | 43:50 | 6:30 | ぎりぎり下回る（97%） |
| 2026年10月（2日まで） | 3:00 | 0:00 | — |

夜勤の深夜帯を前日として数えるため、設定の「日付の区切り時刻」を 05:00 にしてから読み込んでください。基準日を変えて作り直す場合：

```bash
node test-data/make_sample.js 2026-10-02
```

```bash
node test-data/make_overtime_sample.js 2026-10-02
```

## データモデル（概要）

- **Project**：名前、既定タグ、色、メモ、アーカイブ
- **Task**：名前、状態（inbox/next/waiting/calendar/later）、Project、分類、タグ、期限、繰り返し、Waiting確認日、見積（分）、Today、完了
- **Record**：taskId、分類1～5（＝Project › 分類 › タスク名）、タグ、開始・終了、実績/予定、メモ
- 全項目に `updatedAt / updatedBy`、削除は `deleted.{projects,tasks,records}` に履歴

## 制限事項

- 静的Webアプリのため、アプリを閉じている間は通知・自動エクスポートは動きません。計測中のタイマーは閉じても継続し、次に開いたとき経過時間が反映されます
- フォルダ連携は File System Access API 対応ブラウザ（Edge / Chrome）のみ。再起動後にアクセス許可を再確認されることがあります
- 複数のPCで同時に計測するとそれぞれ別の記録になります（マージで両方残ります）
- 祝日の追加ボタンは現行の祝日法に基づいて日付を計算します。法改正や臨時の祝日は一覧を直接編集してください
